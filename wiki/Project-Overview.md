# 溯源遗梦项目完整概述

## 项目简介

"溯源遗梦"是一款使用C++和SDL2开发的卡牌策略游戏，采用水墨风格的视觉设计。游戏以状态机架构为核心，通过丰富的游戏机制和策略元素为玩家提供深度的游戏体验。玩家需要通过构建和管理卡组，在回合制战斗中运用策略击败敌人。

## 技术架构

### 核心技术栈
- **编程语言**: C++
- **图形库**: SDL2（包含SDL2_ttf、SDL2_image）
- **构建工具**: MSBuild (Visual Studio)
- **平台**: Windows

### 项目结构
```
Tracer/
├── src/
│   ├── core/           # 核心系统和基础类
│   ├── states/         # 游戏状态实现
│   ├── ui/             # 用户界面组件
│   └── main.cpp        # 程序入口点
├── assets/             # 游戏资源文件
│   ├── fonts/          # 字体文件
│   ├── narrative/      # 叙事文本文件
│   └── *.png           # 图片资源
├── wiki/               # 项目文档
├── build.bat           # 构建脚本
├── compile.bat         # 编译脚本
└── Tracer.sln          # Visual Studio 解决方案文件
```

## 核心系统

### 状态机架构
游戏采用状态机架构管理所有游戏界面和流程，每个界面都是一个独立的状态类，继承自State基类。这种设计使得界面切换清晰、易于维护，并支持复杂的交互逻辑。

### App类
App类是应用程序的主类，负责管理整个游戏的生命周期，包括：
- 窗口和渲染器管理
- 游戏状态切换
- 全局状态存储（上帝模式、淬炼祝福、蜡烛系统等）

### 核心数据结构

#### Card类
Card类定义了卡牌的基本属性：
- `id`: 全局唯一ID
- `name`: 卡牌名称
- `sacrificeCost`: 献祭消耗
- `category`: 卡牌种类
- `attack`: 攻击力
- `health`: 生命值
- `marks`: 印记列表

#### CardDB类
CardDB是全局卡牌数据库，负责注册和管理所有卡牌原型。

#### DeckStore类
DeckStore是牌组管理系统，管理玩家的牌库、手牌和弃牌堆。

## 游戏机制

### 卡牌系统
游戏包含丰富的卡牌类型和印记系统：

#### 卡牌种类
- 兵器
- 诗篇
- 墨
- 印
- 卷
- 毛皮（平凡之墨、稀有之墨、传奇之墨）

#### 印记系统
印记是卡牌的核心机制，为卡牌提供特殊能力：
- **攻击类**: 横冲直撞、蛮力冲撞、水袭、护主
- **防御类**: 不死、反伤、坚盾
- **特殊机制**: 传承、献祭、成长、检索
- **环境互动**: 风雅扇、日晷、断因剑、吞墨毫

### 战斗系统
战斗在3行4列的网格战场上进行，采用回合制机制：
- 玩家回合：抽牌、放置卡牌、攻击
- 敌人回合：前进、成长、攻击
- 墨尺平衡系统：影响抽牌数量和资源获取
- 献祭系统：通过献祭卡牌获得资源

### 意境刻画系统
独特的卡牌强化系统，通过收集"意"（印记）和"境"（部类）进行组合，为特定部类的卡牌提供额外能力。

### 道具系统
玩家最多可以持有3个道具，道具可以在不同状态下提供不同的效果：
- 战斗增益
- 地图探索增益
- 商店折扣
- 特殊能力

### 地图系统
采用分层节点结构，总共10层：
- 第1层：起始层
- 第2-9层：中间层
- 第10层：Boss层

节点类型包括：起点、普通、Boss、精英、商店、事件。

## 主要游戏状态

### 核心状态
1. **MainMenuState**: 主菜单界面
2. **MapExploreState**: 地图探索界面
3. **BattleState**: 战斗界面
4. **DeckSelectState**: 牌组选择界面

### 功能状态
1. **InkShopState**: 墨坊商店
2. **InkWorkshopState**: 墨工坊
3. **CombineState**: 合卷系统
4. **MemoryRepairState**: 记忆修复
5. **RelicPickupState**: 墨宝拾遗
6. **BarterState**: 以物易物
7. **EngraveState**: 意境刻画
8. **HeritageState**: 文脉传承
9. **SeekerState**: 寻物人
10. **TemperState**: 淬炼
11. **InkGhostState**: 墨魂
12. **WenxinTrialState**: 问心试炼
13. **VictoryState**: 胜利界面
14. **TextPlayerState**: 文本播放界面

## 叙事系统

### 文本播放系统
通过TextPlayerState和NarrativeManager实现游戏中的叙事文本播放：
- 支持预设文本段落播放
- 动态背景图片切换
- 多种播放模式（手动、自动、跳过）
- 状态跳转机制

### 文本格式
```
[PRESET:预设名称]
文本内容
[BG:背景图片路径]带背景的文本内容
end
```

## 用户界面

### 界面组件
- **Button**: 按钮组件，支持悬停效果和点击事件
- **CardRenderer**: 卡牌渲染器，负责卡牌的可视化展示

### 界面设计原则
- 一致性：所有界面使用统一的视觉风格
- 反馈性：用户操作后提供即时反馈
- 简洁性：界面布局清晰，信息层次分明

## 存储系统

### 核心存储类
1. **EngraveStore**: 管理意境刻画系统数据
2. **ItemStore**: 管理全局道具存储
3. **MapStore**: 管理地图数据的持久化存储
4. **WenMaiStore**: 管理文脉值

## 开发规范

### 编码规范
- 类名使用PascalCase
- 函数名使用camelCase
- 变量名使用camelCase
- 私有成员变量以下划线结尾
- 使用#pragma once保护头文件

### 架构原则
- 单一职责原则
- 依赖管理
- RAII资源管理
- 异常安全

## 构建和运行

### 系统要求
- Windows 10或更高版本
- Microsoft Visual Studio 2022 Community或更高版本
- SDL2开发库

### 构建步骤
1. 使用Visual Studio打开Tracer.sln解决方案文件
2. 选择构建配置（Debug或Release）
3. 点击"生成"→"生成解决方案"

或使用命令行：
```cmd
compile.bat
```
或
```cmd
build.bat
```

- 战斗系统与卡牌系统

- 地图系统与各功能节点

## 项目特色

### 核心特色
1. **水墨风格**: 独特的视觉设计，营造诗意武侠氛围
2. **策略深度**: 丰富的卡牌组合和印记系统
3. **叙事体验**: 完整的文本播放系统，增强游戏代入感
4. **系统集成**: 多个子系统有机结合，形成完整的游戏体验

### 游戏深度
1. **多重强化系统**: 淬炼、合卷、文脉传承、意境刻画
2. **多样化玩法**: 战斗、探索、制作、交易
3. **策略多样性**: 不同牌组构建和战斗策略
4. **重玩价值**: 随机元素和多种选择增加重玩性

"溯源遗梦"通过精心设计的系统架构和丰富的游戏内容，为玩家提供了一个深度且富有挑战性的卡牌策略游戏体验。
